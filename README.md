ShareSphere

Community Item Sharing Platform

ShareSphere is a full-stack web application that allows users to register, donate items, view available items, and request items through a simple and responsive platform.

The project demonstrates backend API development, frontend integration, and real-world application deployment.

API Endpoints

Method| Endpoint| Purpose
GET| "/"| Check API status
POST| "/register"| Create new user
POST| "/login"| Authenticate user
POST| "/donate"| Add donated item
GET| "/items"| View available items
POST| "/request-item"| Request an item
